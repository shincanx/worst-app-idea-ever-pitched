A deterministic Python program that writes one sentence — at most 240 characters — pitching the worst, most useless app idea imaginable to /output/entry.txt. The pitch: ParkPal, an AI app that finds and reserves the farthest parking spot from every entrance, so your 10,000 steps start before you even leave the car — walking is the feature, convenience was the bug.

## Run it

```sh
python3 main.py
```
